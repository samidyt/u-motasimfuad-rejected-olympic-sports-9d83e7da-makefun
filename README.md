# Rejected Olympic Sports

One funny single-line sport the Olympics rejected — a made-up event, real
enough to sound like a broadcast, absurd enough to be funny, and short
enough to fit in 200 characters. Entry for the
[Rejected Olympic Sports](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da)
bounty on [make.fun](https://make.fun).

## The entry

> Synchronised napping: four athletes share one air mattress; the first to dream of gold is disqualified.

(103 characters, one line. The twist lands on the last word: dreaming of
gold is the one thing an Olympian must not do.)

## How it works

`main.py` writes that single line to `/output/entry.txt` (UTF-8, 1–200
characters, no trailing newline), which the house AI judge compares
two at a time on funniness, plausibility, economy, and quotability.

```sh
python3 main.py   # writes /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write the entry elsewhere for local checks.
